# 🎱 전국당꼴 (Jeonguk Dang-kkol)
**구글맵 연동 당구 꼴찌 기록기 & 명예의 패배자 랭킹 앱**

친구들과 당구 경기를 한 뒤, 당구장을 터치하여 오늘의 꼴찌와 낸 게임비, 패배 변명을 기록하고 랭킹을 매기는 모바일 앱입니다.

---

## 📱 주요 기능

1. **🗺️ 구글맵 & 인터랙티브 지도 연동**
   * 내 위치 주변 당구장 자동 탐색 및 핀 표시
   * 지도에서 당구장을 터치하면 즉시 해당 당구장 전적 요약 확인
   * 지도 빈 곳을 탭하거나 상단 버튼으로 새로운 당구장 즉시 추가 가능
   * Google Maps API Key가 없어도 고화질 지도로 100% 정상 작동하며, API Key 입력 시 공식 실시간 구글맵으로 자동 전환

2. **💀 오늘의 꼴찌 등록 (박제 기능)**
   * 경기 종목 선택: 4구, 3구(중대), 3구(대대), 포켓볼
   * 패배자(꼴찌) 이름 입력 (최근 대결한 친구 퀵 버튼 지원)
   * 꼴찌가 낸 게임비 입력 (1만, 1.5만, 2만 등 퀵 버튼 지원)
   * 패배자의 명언/변명 선택 ("오늘 큐대가 휨", "초크 안 칠함", "쿠션 덜 먹힘" 등)

3. **🏆 전국 꼴찌 명예의 전당 & 통계**
   * **최다 꼴찌 순위**: 누가 제일 많이 졌는지 패배 횟수 순위
   * **지갑 털린 순위**: 누가 게임비를 제일 많이 냈는지 총 지출 금액 순위 (영구 물주 뱃지 💸)
   * **당구장별 단골 꼴찌**: 특정 당구장에서 유독 많이 지는 친구 징크스 분석

4. **📜 경기 기록 & 공유**
   * 상세 히스토리 내역 확인 및 삭제
   * 카카오톡 단체방 공유 문구 자동 생성 ("오늘 00당구장에서 철수님이 꼴찌로 선정되었습니다!")

5. **💾 데이터 영구 보관 & 백업**
   * 스마트폰 로컬 저장소(LocalStorage)에 영구 보관 (인터넷이 없어도 작동)
   * JSON 백업 파일 내보내기 & 불러오기 지원

## 🚀 빠른 시작 (PC / 모바일 브라우저 즉시 실행)

1. `앱_실행하기.bat` 파일을 더블 클릭하면 기본 웹 브라우저에서 즉시 실행됩니다.
2. 브라우저에서 `F12`를 누른 뒤 좌측 상단의 **모바일 화면 전환 아이콘(Ctrl+Shift+M)**을 누르면 실제 스마트폰 화면 비율로 편리하게 테스트하실 수 있습니다.

## 📦 안드로이드 APK 파일 빌드 방법

### 방법 1: GitHub Actions 자동 빌드 (가장 추천 / 무설치 2분 완성)
PC에 무거운 Android Studio나 Java를 설치하지 않고 무료 클라우드에서 바로 `.apk`를 빌드하는 방법입니다:

1. 본 폴더(`전국당꼴`)의 파일들을 깃허브(GitHub) 저장소에 푸시(업로드)합니다.
2. GitHub 저장소 상단의 **Actions** 탭으로 이동합니다.
3. `Build Android APK (전국당꼴)` 워크플로우가 자동으로 실행되어 1~2분 내에 빌드가 완료됩니다.
4. 완료된 빌드 결과물에서 **`전국당꼴-debug-apk`**를 클릭해 다운로드합니다.
5. 다운로드한 `.apk` 파일을 스마트폰으로 전송(카카오톡 나에게 보내기, 구글 드라이브 등)하여 설치합니다.

### 방법 2: Android Studio에서 직접 빌드
1. **Android Studio**를 실행하고 `File > Open`을 누릅니다.
2. `c:\00_주식\전국당꼴\android` 폴더를 선택하여 엽니다.
3. Gradle 동기화가 완료되면 상단 메뉴 `Build > Build Bundle(s) / APK(s) > Build APK(s)`를 클릭합니다.
4. 빌드가 완료되면 우측 하단 알림창의 `locate`를 클릭하여 생성된 `app-debug.apk`를 바로 확인하실 수 있습니다.
